2125C24 GEAR LEVER KNOB - R + R

Applies to: engines: 2.0 JTS; all production periods

Removing

Refitting
  • Open the button for the manual gearbox lever boot.
  • Undo the gear lever grip and remove it.
  • If necessary, remove the gear lever trim.

Applies to: engines: 2.0 JTS; all production periods

Refitting

Removing
  • Place the gear lever trim back in its housing.

Take care to position the notch on the trim correctly in relation to the reference on the lever.

  • Tighten the gear lever grip in place.
  • Close the button for the manual gearbox lever boot.

Applies to: engines: 3.2 V6; all production periods

Removing

Refitting
  • Oopen the button (1a), then release and remove the manual gearbox lever boot (1b) working on the retaining clips.

Applies to: engines: 3.2 V6; all production periods

1. Remove the gear lever grip (1a) using the tool (1b).

Protect the contact areas between the gear lever grip and the tool to prevent surface damage using felt, bodywork tape, etc.
