Removing

Refitting

Lift up the load carrying compartment trim.

Release the tailgate seal by the luggage compartment moulding.

1. Undo the bolts securing the moulding.

2. Release the retaining plugs (2a) using the special tool, then undo the bolts (2b) underneath.

-

3. Remove the luggage compartment moulding.

Applies to: all engines; all production periods

Refitting

Removing

Check that the moulding is undamaged.

Position the moulding and secure it using the fixing bolts.

Position the retaining plugs.

Fit the tailgate seal.

Reposition the load carrying compartment covering.
