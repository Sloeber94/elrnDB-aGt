M01 ELECTRIC FRONT WINDOWS / NOT WORKING

Applies to: all engines; all production periods

With the ignition key in the ON position, when the buttons on the doors are operated, the electric front windows do not work at all.

Applies to: all engines; all production periods

To ensure that the windows close fully in doors without an upper frame, the electric windows have a system known as short drop. For more information on the subject see [DF_7005M]

Applies to: all engines; all production periods
