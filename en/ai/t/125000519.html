The ABS warning light does not come on and system is observed to work irregularly.

Applies to: all engines; all production periods

Results of the tests

1

CHECK WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the Examiner diagnostic equipment to the diagnostic connector and check the following at the brake nodes:

  • For faults in error mode
  • In the parameters ambient, the plausibility of all the parameters
  • In the active diagnosis ambient, the operation of the ABS warning light

Continue to Step 2

Presence of faults

Continue according to the instructions for the diagnostic equipment

The warning light does not come on

Continue according to the instructions in

See table

See table K61 ABS WARNING LIGHT OFF / (DO NOT CARRY OUT INITIAL TEST)

2

CHECKING BRAKE HYDRAULIC SYSTEM

All OK

Problems met

Operation

Disconnect the ABS electrical connection and test the efficiency of the braking system with the aid of a service rig.

Continue to Step 3

Braking action not balanced

Overhaul the braking system

3

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

The test is essential, as the braking system is a safety feature of the car

End of diagnosis

Fault persists

Replace the brake system hydraulic unit Op.

Op. 3340A12 ABS HYDRAULIC AND ELECTRONIC CONTROL UNIT
