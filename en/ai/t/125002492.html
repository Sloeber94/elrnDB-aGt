Applies to: all engines; all production periods

Functional description

The CODE unit inside Body Computer

M1 is supplied from the battery from the line of maxifuse CPL B99 (B5 for the 3.2 V6 engine) pin 18 of connector F, while the ignition-operated power supply (INT) reaches pin 9.

The line leading from pin 29 of connector A of

M1 is a serial line connected to the engine management unit M10 which is responsible for the communication required for identifying the key and exchanging codes.

The aerial of CODE device

P91 is connected via two leads to the CODE unit of M1, at pins 4 and 5 of connector A;

The aerial is located coaxially on the ignition switch so that it can register key insertion and activation.

Body Computer

M1 is linked to instrument panel E50, via the CAN line to manage the CODE failure warning light.
