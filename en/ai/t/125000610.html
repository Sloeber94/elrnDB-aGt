Applies to: engines: 2.0 JTS, 3.2 V6, 1.9 JTD 16V; all production periods

The brakes node sends the ABS warning light on message via the C-CAN network to the body computer which, through the gateway, makes it available via the B-CAN network to the instrument panel node.Warning: If there are faults at the C-CAN, the control unit failure warning lights will light up. The CAN INFORMATION CHECK is designed precisely for this purpose

Applies to: engines: 2.0 JTS, 3.2 V6, 1.9 JTD 16V; all production periods
