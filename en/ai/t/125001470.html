4450A40 REAR WHEEL GEOMETRY - CHECK USING OPTICAL EQUIPMENT

Applies to: engines: 1.9 JTD 16V; all production periods

  • Position the vehicle on a test bench, with sliding plates on all the wheels.
  • Arrange the vehicle in standard A load condition (empty + full tank of fuel)
  • Check that the tyre inflation pressure is correct.

GEOMETRY CHECK

  • Check that the rear wheel geometry is within required limits.

Measurement

Value

-

Rear wheel geometry D - C (mm)

A vehicle unladen with full tanks

22.9

Applies to: engines: 1.9 JTD 16V; all production periods

CAMBER CHECK

  • Check that the rear wheel camber is correct.

Measurement

Value

-

Rear wheel camber - c

A vehicle unladen with full tanks (standard A)

- 35’ ± 20’

The rear wheel camber cannot be adjusted. If the value does not correspond to the recommended figures, check the condition of the suspension components.

Applies to: engines: 1.9 JTD 16V; all production periods

TOE IN CHECK

  • Check that the rear wheel toe-in is within specified limits

Measurement

Value

-

Rear wheel toe in D2 - D1 (mm)

A vehicle unladen with full tanks (standard A)

+ 3 ± 1

The rear wheel toe in angle is +27’ ± 9’.

The toe in value, is calculated using a 15" wheel rim irrespective of the wheel size actually fitted; if it is not possible to use a 15" wheel on the test bench, refer to the original values.It should also be remembered that the toe in value includes the tolerance that should be equally distributed between the two wheels.

Applies to: engines: 1.9 JTD 16V; all production periods

  • If the rear wheel toe in value is not within the recommended figures, adjust it following the instructions given below.
  • Undo the nuts, then adjust the cam bolts (1a) fixing the rear wheel toe in rods (1b) to the rear suspension crossmember.

Applies to: engines: 1.9 JTD 16V; all production periods

  • Tighten the nuts to the recommended torque.
