Applies to: all engines; all production periods

When the alarm is on, the system will not come on again after one boot lid open/closure cycle.

Applies to: all engines; all production periods

One second after the boot lid opening command (via remote control), the system automatically reactivates if boot lid opening is not detected by turning volumetric, anti-tilt and perimeter protections back on.

Applies to: all engines; all production periods
