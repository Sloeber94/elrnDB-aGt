Applies to: all engines; all production periods

The automatic demisting function does not work with the climate control system switched on

Applies to: all engines; all production periods

In systems where there is the 'automatic demister' function with the windscreen misted up and the climate control system on automatic operation, the control unit acts by increasing the fan speed - orientating the air distribution to the windscreen and sides

Applies to: all engines; all production periods
