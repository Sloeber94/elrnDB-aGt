Applies to: all engines; all production periods

The alarm system does not go off when boot opening is controlled via the remote control or mechanical key.

Applies to: all engines; all production periods

When in operational mode, the system disables the external volumetric/anti-tilt modules and the perimeter protection from the boot switch input when a boot lid opening control is received.

Applies to: all engines; all production periods
