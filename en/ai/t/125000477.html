SENSOR REPLACEMENT

All OK

Problems met

Operation

If there is a gear engagement sensor error and no faults are detected at the connections/wiring, replace it Op. 2127E42

and check that the position reading is correct by carrying out a series of C.M.

It is advisable to fit tool n° 1870753001 before removing the potentiometer from the hydraulic unit

If there is a gear selector sensor error and no faults are detected at the connections/wiring, replace it Op. 2127E40

and check that the position reading is correct by carrying out a series of C.M.

ROAD TEST

All OK

Problems met

Operation

Carry out a road test, making sure to make as many gear changes as possible with all the available gears (under different engine speed and load conditions).

Check the failed engagement counters in the parameters environment (failed engagement counters in: neutral, 1st-5th and Reverse).

  • Print out/make a note of the new counter values. Compare the new values of the parameters with those noted down previously, checking that there is not a signficant increase for one or several counters

End of diagnosis

THE FAULT PERSISTS

All OK

Problems met

Operation

The fault may be caused by false contacts on the gear lever: check the state of the connections and wiring for the lever.

  • In any event, contact Technical Service for further information on the problem.
