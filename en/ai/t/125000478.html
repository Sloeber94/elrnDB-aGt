CONTROL UNIT ERRORS CHECK

All OK

Problems met

Operation

Check that there are no control unit errors. In particular:

  • Brake switch error
  • Clutch sensor error
  • Even gear engagement error
  • Odd gear engagement error
  • Clutch solenoid current error
  • 1st/2nd selection solenoid valve error
  • 5th/Reverse selection solenoid valve error
  • Control unit earth error
  • Load relay error

Pump relay error

If there is a brake switch error, the recovery considers the brake to be constantly pressed with the engine running; this means that only changes to lower gears can take place in automatic mode

Continue to Step 7

Presence of one or more of the errors included in the list
