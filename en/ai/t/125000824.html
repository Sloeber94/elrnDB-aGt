Applies to: engines: 2.0 JTS; all production periods

Position the vehicle on a lift.

Check that the tread on the tyres is not worn unevenly.

Some types of tyre are fitted with wear gauges; they should be replaced as soon as these gauges are visible.

Do not cross exchange tyres.

Check that the tyre inflation pressure is correct, including the spare.

The tyre inflation pressure should be checked with the tyres cold.

Check that the lighting system is working properly: headlights, direction indicators, hazard warning lights, luggage compartment light, passenger compartment light, glove compartment light and instrument panel warning lights.

Check that the windscreen wash/wipe system is working properly and, if necessary, adjust the jets.

Check that the windscreen and rearscreen wiper blades are correctly positioned and not worn.

Check that the front brake disc pad wear sensor is working properly.

Visually inspect:

  • bodywork exterior
  • underbody protection
  • rigid and flexible sections of pipes (exhaust - fuel system - braking system)
  • rubber elements (boots, hoses, bushes, etc.).

Visually inspect the condition of the single engine components drive belt.

Check and, if necessary, top up the brake-clutch fluid level

Op. 0010T64 BRAKE AND OR CLUTCH FLUID CHECK LEVEL AND TOP UP AS NECESSARY.

Check and, if necessary, top up the power assisted steering fluid level

Op. 0010T71 POWER STEERING FLUID CHECK LEVEL AND TOP UP IF NECESSARY.

Check and, if necessary, top up the windscreen washer fluid level.

Check and, if necessary, top up the battery fluid level.

Check and, if necessary, top up the engine coolant level.

Op. 0010T20 COOLANT CHECK DENSITY AND TOP UP IF NECESSARY.

Applies to: engines: 2.0 JTS; all production periods; only with equipment: Smart gearbox

Check and, if necessary, top up the Selespeed gearbox fluid level

Op. 0010T47 HYDRAULIC SYSTEM FLUID FOR GEARBOX WITH HYDRAULIC SELECTION CHECK LEVEL AND TOP UP IF NECESSARY.

Applies to: engines: 2.0 JTS; all production periods

Visually inspect the condition of the timing drive belt.

Proceed with changing the engine oil and filter

Op. 0010T12 ENGINE OIL AND FILTER REPLACE.

Proceed with changing the brake fluid

Op. 0010T62 POWER STEERING FLUID CHECK LEVEL AND TOP UP IF NECESSARY.

Proceed with replacing the active charcoal combination particle filter

Op. 5010B09 PURIFYING FILTER (ANTIPOLLEN) FILTER ELEMENT - REPLACE.

At the end of the service, connect the Examiner diagnostic equipment to the diagnostic socket in the vehicle and make a connection with the "MANNESMAN VDO INSTRUMENT PANEL".

Before carrying out the active diagnosis "INSPECTION SERVICE VALUE" check under "UNIT" in the instrument panel menu that the value has been set to km or miles depending on the unit of measurement in the country.

Inside the "Active diagnosis" ambient, carry out the "INSPECTION SERVICE VALUE" procedure to memorize/update the mileage value at which the service was carried out.

Check in the instrument panel "SERVICE" menu that for countries using km as their unit of measurement that "20,000" km is displayed whilst for countries using miles as their unit of measurement the mileage shown corresponds to "12,427".
