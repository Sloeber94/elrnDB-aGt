Applies to: all engines; all production periods

The driver's and passenger's electric windows only work in manual mode; when the control button is pressed for over 300 ms and released, the window does not close automatically, but instead stops.

Applies to: all engines; all production periods

The Driver's Door Node unit is programmed to open and close the driver's window both manually and automatically, while the passenger's window can close only manually, while it can open both manually and automatically. The control unit activates the manual function if the control button is pressed for a period of between 60 and 300 ms (short time), while it actibates the automatic function if the control button is pressed for over 300 ms (long time).

Applies to: all engines; all production periods
