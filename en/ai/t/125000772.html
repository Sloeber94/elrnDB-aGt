2127H CHECK ON AUTO BUTTON AUTOMATIC OPERATION SELECTION

Applies to: engines: 2.0 JTS; all production periods; only with equipment: Smart gearbox

Turn the ignition key to the ON position.

Connect the Examiner diagnostic equipment and select the input status display (ON/OFF) for the City button.

Press and release the automatic operation button at the bottom of the gear lever (the check is carried out with the engine on).

Check that the state has changed using the Examiner.

Start up the engine and check that when the button is pressed the word 'CITY' appears on the display.
