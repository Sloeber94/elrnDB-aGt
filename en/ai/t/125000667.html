With the belt fastened and the vehicle stationary, when making gentle movements (for example, picking up an object) the seat belt locks easily and/or remains locked

Applies to: all engines; all production periods

Results of the tests

1

REEL CHECK

All OK

Problems met

Operation

Check that the reel is fitted correctly, checking that the reference pin is correctly positioned in the bodyshell housing

Continue to Step 2

Fitting irregular

Loosen the fixing bolt and position the reference lug correctly Retighten the bolt to the recommended torque

2

CHECK FOR PRESENCE OF FOREIGN BODIES

All OK

Problems met

Operation

Check that there are no foreign bodies inside the system

Continue to Step 3

Presence of foreign bodies

Remove foreign bodies

3

BELT CHECK

All OK

Problems met

Operation

Check that there is no interference, deformation or marks caused by accidents

Continue to Step 4

There is interference which slows down the sliding of the front belts

Eliminate the interference, if necessary, replace the belts Op.

There is interference which slows down the sliding of the rear side belts

Eliminate the interference, if necessary, replace the belts Op.

Eliminate the interference, if necessary, replace the belt Op.

4

PRETENSIONER OPERATION CHECK

All OK

Problems met

Operation

Check that the pretensioner has not been activated as the result of an accident. If this is the case, there would be white powder on the spring casing, the reel would be locked and/or the belt deteriorated

Continue to Step 5

Evidence of pretensioner activated

Replace the belt Op.

Op. 7065A12 FRONT SEAT BELT (ONE), LH OR RH, WITH PRETENSIONER ON WHEEL - R R

5

REEL RELEASE SYSTEM CHECK

All OK

Problems met

Operation

Check the reel release, rewinding the belt for a brief section and gently unwinding it

Continue to Step 6

Front reel release system faulty

Replace the front belt Op.

Op. 7065A12 FRONT SEAT BELT (ONE), LH OR RH, WITH PRETENSIONER ON WHEEL - R R

Rear side reel release system faulty

Replace the side rear belt Op.

Op. 7065B10 L/H OR R/H REAR SAFETY BELT (ONE) - R+R

Rear centre reel release system faulty

Replace the centre rear belt Op.

Op. 7065B18 CENTRE REAR SEAT BELT - R.R.

6

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present
