Applies to: all engines; all production periods

When the vehicle is moving, the accidental operation of the handbrake is not indicated by the acoustic signal.

Applies to: all engines; all production periods

The instrument panel node acquires from the network the signal indicating the status of the handbrake switch and the vehicle speed. If the handbrake is operated and the vehicle speed exceeds 4 km/h, an acoustic signal is emitted.Warning: This function can be enabled/disabled via the MODE +/- keys on the controls switch panel unit. Make sure that the function has not been disabled incorrectly by the user
