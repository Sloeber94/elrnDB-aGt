Applies to: engines: 1.8 T.SPARK; all production periods

The engine management control unit warning light and the CODE warning light do not come on. The I.E. warning light should come on at Key-on and go out when the engine starts up; the CODE warning light should come on at Key-on and go out after the initial test on versions with low line instruments; in versions with high line instruments, the CODE warning light only comes on if there is a fault.

Applies to: engines: 1.8 T.SPARK; all production periods

The failure of both warning lights to come on is due to supply problems

Applies to: engines: 1.8 T.SPARK; all production periods
