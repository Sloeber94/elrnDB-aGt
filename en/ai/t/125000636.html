M03 ONE OF THE ELECTRIC FRONT WINDOWS IS NOT WORKING

Applies to: all engines; all production periods

With the ignition key in the ON position one of the electric front windows does not wor under any circumstance when the relevant button is operated.

Applies to: all engines; all production periods

each of the front windows is controlled by the switch in the door panel; the switch on the driver's door, in particular, can also control the movement of the front passenger window.

Applies to: all engines; all production periods

To ensure that the windows close fully in doors without an upper frame, the electric windows have a system known as short drop. For more information on the subject see [DF_7005M]

Applies to: all engines; all production periods
