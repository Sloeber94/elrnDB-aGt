Applies to: engines: 2.0 JTS, 3.2 V6, 1.9 JTD 16V; all production periods

WARNINGS

Use care when working on trim components and use the specified tools correctly in order to avoid damage.

PRECAUTIONS

Before working on the electrical system (connectors, electrical components, wiring, etc.) turn the ignition off (STOP) and DISCONNECT THE BATTERY.

Each time the battery terminal leads are disconnected, the (right and left) electric windows control unit initialization procedure must be carried out to programme the door window end of travel, refer to

Op. 7005M40 FRONT ELECTRIC WINDOW SYSTEM ECU - R+R FOLLOWING ELECTRICAL WIRING CHECK
