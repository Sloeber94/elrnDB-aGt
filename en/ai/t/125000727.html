PRELIMINARY CHECKS

Operation

Stiffening of the steering detected

Continue according to the instructions in

Noise from the steering detected

Identify and eliminate the cause of the noise

1

RESERVOIR LEAK CHECK

All OK

Problems met

Operation

Visually check that there are no leadks from the power assisted steering fluid reservoir

Continue to Step 2

Leaks from the reservoir

Replace the reservoir Op.

Op. 4130B10 POWER STEERING FLUID RESEVOIR R R

2

PIPES CHECK

All OK

Problems met

Operation

Visually check, using talc, that there are no leaks from the connectors for all the power assisted steering system pipes, flexible and rigid.

Continue to Step 3

Leaks from the system

Tighten the connectors or replace the damaged parts, replacing all the seals

3

STEERING BOX CHECK

All OK

Problems met

Operation

Visually check that there are no leaks (using talcum powder):

  • From the rigid pipes at the steering box and attachments;
  • From the steering box lower plug;
  • From the steering column attachment;
  • From the actual steering box

Continue to Step 4

Leaks from the rigid pipes

Tighten the connectors or replace the steering box Op.

Op. 4130A10 POWER STEERING BOX - R+R - CHECK TOW-IN IF NECESSARY SEPARATELY - INCLUDES BLEEDING

Leaks from the steering column attachment or from the actual steering box

Replace the steering box Op.

Op. 4130A10 POWER STEERING BOX - R+R - CHECK TOW-IN IF NECESSARY SEPARATELY - INCLUDES BLEEDING

4

STEERING BOX BOOTS CHECK

All OK

Problems met

Operation

Inspect the steering box boots and check that there is no fluid

Continue to Step 5

Leaks from the steering box seals

Replace the steering box Op.

Op. 4130A10 POWER STEERING BOX - R+R - CHECK TOW-IN IF NECESSARY SEPARATELY - INCLUDES BLEEDING

5

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present
