Applies to: all engines; all production periods

With the vehicle moving, the accidental opening of one of the doors or the boot is not indicated by the buzzer.

Applies to: all engines; all production periods

The instrument panel node acquires from the network the signal indicating the status of the door switches or boot and the vehicle speed. If a door or the boot are opened and the vehicle speed is over 4 km/h, an acoustic signal is emitted.Warning: This function can be enabled/disabled via the MODE +/- keys on the controls switch panel unit. Make sure that the function has not been disabled incorrectly by the user

Applies to: all engines; all production periods
