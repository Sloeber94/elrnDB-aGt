Applies to: all engines; all production periods

Description

The are two lights in the front doors which light up the ground.

When the front doors are opened, the Body Computer notifies the door control unit of the status of the doors. The latter switches on the lights in the doors.

The function is activated both with the ignition switched OFF or ON.

The lights come on for a maximum of 3 minutes when one of the front doors is opened; when this time has elapsed the lights can only be turned on again if one of the doors is opened again.

The lights go out immediately if both of the doors are closed.

The Body Computer continuously acquires the 'battery voltage' signal and compares it with a limit: if the battery voltage level goes below this limit, it intervenes via the CAN using a signal to disable a series of loads: these include the door courtesy lights; the function is activated with the ignition key in the OFF position.
