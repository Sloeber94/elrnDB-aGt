Refitting

Op. 7040H80 PARCEL RACK

Op. 7040G30 BOOT LIGHT BULB HOLDER - R R

(right side)

Op. 7065C86 BOOT/LOAD PLATFORM POWER UNIT HOUSING - R R

(left side)

Op. 5570T85 CD/AUDIO PLAYER LOADER - R R

(left side)

Release the rear tailgate seal by the boot compartment.

1. Remove the cover (1a) and undo the bolt (1b) underneath.

2. Release the inner retaining clips (2a) using the knife and extract the rear pillar trim (2b) leaving it fitted on the rear seat belt.

Work carefully if a Head Bag is fitted.

Applies to: all engines; all production periods

1. Undo the fixing bolts (1a) and remove the boot compartment (1b).

Applies to: all engines; all production periods

Refitting

Removing

Check that the boot compartment is not damaged.

Position the boot compartment and secure it using the fixing bolts.

Fit the rear pillar trim using the inner clips.

Tighten the bolt fixing the rear pillar trim and reposition the protective cover.

Work carefully if a Head Bag is fitted.

Fit the tailgate seal by the boot compartment.

Op. 5570T85 CD/AUDIO PLAYER LOADER - R R

(left side)

Op. 7065C86 BOOT/LOAD PLATFORM POWER UNIT HOUSING - R R

(left side)

Op. 7040G30 BOOT LIGHT BULB HOLDER - R R

(right side)

Op. 7040H80 PARCEL RACK

Connect the negative battery terminal lead.
