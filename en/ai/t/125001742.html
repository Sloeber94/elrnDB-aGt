PRECAUTIONS

PRECAUTIONS

Before working on the electrical system (connectors, electrical components, wiring, etc.) turn the ignition key OFF and DISCONNECT THE BATTERY.

Work carefully on the fittings and use the recommended tools correctly to prevent damage.

CODE - ALARM SYSTEM COMPONENT MANAGMENT

Data base for code and alarm system parts management

There is a centralized DATA BASE (for all markets) managed by the PARTS DIVISION for ordering all CODE system components and some of the alarm system components.

The production plant transfers all the necessary data into this data base together with the chassis number of the new vehicle.

This data base is then used for ordering components that need replacing by the Dealer Network.

The data base contains numerous pieces of information, such as:

  • vehicle chassis no.;
  • secret code;
  • code for each key (transponder identification);
  • remote control code;
  • mechanical key code;
  • programming data;

If one of the CODE - alarm system components needs replacing and is being ordered, follow the procedures described below.

Lost key/s (mechanical or key with remote control)

Ask the Customer for all the remaining keys in their possession. They should also prove that they are the owner of the vehicle by producing the registration document and identification data.

Deleting codes of lost keys from the body computer memory

Connect the Tester to the vehicle tester output and run the following procedure.

1. Set the Body Computer to "Code Acquisition" mode.

2. Insert the remaining keys into the ignition in sequence.

3. Exit "Code Acquisition" mode: The IDs of keys not inserted will be deleted from the Body Computer memory.

4. Set the Body Computer to "Remote Control Code Acquisition" mode.

5. Press the keys of the remaining remote control units in sequence.

Applies to: engines: 1.9 JTD 16V; all production periods

6. Exit "Remote Control Code Acquisition" mode: The IDs of remote control units not inserted will be deleted from the Body Computer memory.

Applies to: all engines; all production periods

At the end of the procedure, pring a table showing the identification code/s still enabled. If no printer is available, copy the codes from the screen onto the FIAT PARTS system form.

Only if the Body Computer already contains 8 keys, send the codes to Fiat Parts to update the DATABASE.

Requesting a new key

Use the Personal Computer supplied to log onto Fiat Parts. Enter the chassis no. of the customer's car, the model code and set up a VOR order to request the key/s (entering the part number) and specify the quantity.

Note that the Body Computer is designed to store up to 8 keys. It is not therefore possible to accept orders when the sum of the number of existing keys and the number of keys ordered exceed this quantity. Keep a record of the form used to order the keys in order to monitor the situation.

Programming key codes into the body computer memory

Once the new key/s have been received from Fiat Parts, ensure that all the old keys in the customer's possession are available.

Connect the Tester to the vehicle tester output and run the following procedure.

1. Set the Body Computer to "Code Acquisition" mode.

2. Insert all the keys (old and new) into the ignition in sequence.

3. Exit "Code Acquisition" mode.

4. Then set the Body Computer to "Remote Control Code Acquisition" mode.

5. Press all the remote control units, old and new, in sequence: it may take several seconds to initialise the new remote control units.

6. Exit "Remote Control Code Acquisition" mode:

7. Check system operation before returning the vehicle to the customer by starting it up using all the keys and opening/closing the doors using the remote control unit (if applicable).

Ordering a new key (mechanical or key with remote control)

Proceed as described above, but no deletion is necessary. Order a new key from Parts and store it (if it comes with a remote control unit, the SEED and ID must also be stored).

If the Body Computer memory already contains 8 stored keys, run the deletion procedure if keys have been lost.

Note that the Body Computer is designed to store up to 8 keys. It is not therefore possible to accept orders when the sum of the number of existing keys and the number of keys ordered exceed this quantity. Keep a record of the form used to order the keys in order to monitor the situation.

In the case of operating faults, it is possible to order spare parts only, but it is absolutely forbidden to exchange electronic control units and/or transponders between different keys because it will not be possible to service the vehicle in the future.

Replacing key lock barrels

This becomes necessary when one or more door lock barrels and/or the ignition key barrel are forced.

Ask the Customer for all the remaining keys in their possession. They should also prove that they are the owner of the vehicle by producing the registration document and identification data.

Use the Personal Computer supplied to log onto Fiat Parts. Enter the chassis no. of the customer's car, the model code and set up a VOR order to order a single key kit (entering the part number) for the vehicle type and specification.

A single cylinder or a kit with the mechanical key code only cannot be ordered.

Programming key codes into the body computer memory

Once the new key kit is received from Fiat Parts, replace the barrels on the door locks and ignition key.

Connect the Tester to the vehicle tester output and run the following procedure.

1. Set the Body Computer to "Code Acquisition" mode.

2. Insert all the new keys into the ignition in order to recognise the new transponder ID codes.

3. Exit "Code Acquisition Mode". Keys not inserted will not be usable for start-up.

4. Then set the Body Computer to "Remote Control Code Acquisition" mode to recognise the SEEDs and IDs of the new remote control units.

Applies to: engines: 1.9 JTD 16V; all production periods

5. Press all the new remote control units in sequence: it may take several seconds to initialise the remote control units.

Applies to: all engines; all production periods

6. Exit "Remote Control Code Acquisition" mode:

7. Check system operation before returning the vehicle to the customer by starting it up using all the keys and opening/closing the doors using the remote control unit (if applicable).

If the customer already owns 2 keys prior to the loss, order further keys as indicated previously (ORDERING NEW KEYS) and remember to insert all keys by means of the appropriate procedure.

Lost code card

The Customer must prove that he or she is the owner of the vehicle by producing the registration document and identification data.

Use the Personal Computer supplied to log onto Fiat Parts. Enter the chassis no. of the customer's car, the model code and set up a VOR order to order a single Code Card (entering the part number).

Once it has been received from Fiat Parts, deliver the new Code Card to the Customer.

Body computer operating fault

Ensure the fault reported by the Customer is due to a body computer malfunction.

Ask the Customer for all the remaining keys in their possession. They should also prove that they are the owner of the vehicle by producing the registration document and identification data.

Use the Personal Computer supplied to log onto Fiat Parts. Enter the chassis no. of the customer's car, the model code and set up a VOR order to order a single Body Computer (entering the part number to identify the version).

Once the new programmed Body Computer has been received from Fiat Parts, proceed as follows:

1. Check the Body Computer serial number stamped on the plate applied to the order form corresponds to that shown on the Body Computer.

2. Check the vehicle chassis no. printed on the plate applied to the order form corresponds to the vehice chassis no.

3. If all codes correspond, install the Body Computer on the vehicle instead of the malfunctioning unit.

4. Connect the Tester to the tester output on the vehicle.

5. Set the Body Computer to "Code Acquisition" mode.

6. Insert all the keys in the customer's possession into the ignition for recognition of the keys that are still enabled.

7. Exit "Code Acquisition" mode: The IDs of keys not inserted will be deleted from the Body Computer memory.

8. Set the Body Computer to "Remote Control Code Acquisition" mode.

9. Press the remote control units in the Customer's possession in sequence in order to ensure the remote control units that are still enabled are recognised.

10. Exit "Remote Control Code Acquisition" mode: The IDs of remote control units not inserted will be deleted from the Body Computer memory.

11. Check system operation before returning the vehicle to the customer by starting it up using all the keys and opening/closing the doors using all the remote control units available (if applicable).

Engine control unit operating fault

A possible fault in the electronic injection control unit should always be confirmed through a thorough check using the Examiner or other diagnostic equipment.

Ask the Customer for all the remaining keys in their possession. They should also prove that they are the owner of the vehicle by producing the registration document and identification data.

Use the Personal Computer supplied to log onto Fiat Parts and set up a VOR order to request a single Engine Control Unit (entering the part no.).

Once a new blank Engine Control Unit has been received from Fiat Parts, install it on the vehicle in place of the malfunctioning unit.

Applies to: engines: 1.9 JTD 16V; all production periods

Initalise the Control unit by turning the ignition on with the enabled keys so that the FIX CODE resident in the Body Computer is transferred to the Engine Control Unit.
