When the system is activated using the remote control unit, the system activates correctly (visual/acoustic signals and deterrent led working), but the door lock system does not work.

Applies to: all engines; all production periods

When the body computer node receives an alarm activation/deactivation signal, it sends a door open/closure signal to the driver's door node (which controls the driver's front door catch) and the passenger door node (which controls the passenger front door catch) via the B-CAN Node. The body computer node controls boot opening/closure directly (according to the boot control settings).

Applies to: all engines; all production periods
